Deskripsi Web GIS

Bagian ini menjelaskan tujuan pembuatan Web GIS dan informasi yang ditampilkan pada peta.

Web GIS persebaran rumah sakit di Kabupaten Lampung Tengah dibuat untuk membantu pengguna memahami lokasi fasilitas kesehatan secara spasial. Melalui tampilan peta interaktif, informasi rumah sakit tidak hanya ditampilkan dalam bentuk daftar, tetapi juga divisualisasikan berdasarkan posisi geografisnya.

Peta ini dapat dimanfaatkan sebagai media pembelajaran geografi, khususnya dalam memahami penggunaan Sistem Informasi Geografis untuk memetakan fasilitas umum. Selain itu, tampilan Web GIS juga memudahkan pengguna dalam mengeksplorasi data rumah sakit karena dapat diperbesar, digeser, dan dibuka dalam mode layar penuh.

Panduan Penggunaan

Ikuti tahapan berikut agar penggunaan peta menjadi lebih mudah dan terarah.

1

Baca Informasi Awal

Pengguna dapat membaca deskripsi singkat untuk memahami tujuan Web GIS dan wilayah kajian yang digunakan, yaitu Kabupaten Lampung Tengah.

2

Klik Menu Peta

Gunakan menu navigasi di bagian atas atau tombol mulai jelajahi peta untuk menuju bagian peta interaktif.

3

Eksplorasi Titik Lokasi

Perbesar, perkecil, geser peta, dan klik titik lokasi untuk melihat informasi rumah sakit secara lebih jelas.

Peta Interaktif

Peta berikut menampilkan persebaran rumah sakit di Kabupaten Lampung Tengah. Gunakan fitur zoom dan geser peta untuk melihat lokasi secara lebih detail.
